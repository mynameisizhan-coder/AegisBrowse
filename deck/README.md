# Submission deck

The six-slide AegisBrowse SIH 2026 submission deck (SIH26171, team NEXORA_), in the
official idea-presentation format:

| File | Use |
|---|---|
| `NEXORA_AegisBrowse_Deck.pdf` | The file to upload — the SIH portal accepts PDF only |
| `NEXORA_AegisBrowse_Deck.pptx` | Editable source |

Every figure on slides 4 and 5 is measured, not estimated. They come from
`nexora_benchmark/` and are listed with reproduction commands in
[`nexora_benchmark/SELECTIVE_RESULTS.md`](../nexora_benchmark/SELECTIVE_RESULTS.md).
`verify_package.sh` checks that the stored results still match the deck.
